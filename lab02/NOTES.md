Рабочая папка - это обычная папка на компьютере, где вы работаете с файлами проекта
Индекс - это промежуточное хранилище
Коммит - это фиксация изменений

Git и GitHub и Brach различаются следующим:
	Git - система контроля версий
	GitHub - хранилище репозиториев
	Branch - независимая линия разработки внутри одного репозитория (ветка)

git status - показывает текущее состояние репозитория
git diff - сравнивает рабочее дерево с индексом
git diff --staged - показывает разницу между индексом и последним коммитом
