git diff - сравнивает рабочую директорию с индексом
git show - показывает содержимое конкретного коммита (по умолчанию последнего)
git log - показывает историю коммитов

git restore - берет версию файла из индекса и записывает ее в рабочее дерево
git restore sorce=... - берет версию файла из конкретного source (к примеру 4 коммита назад)

git reset --hard - передвигает указатель HEAD на выбранный коммит, также обновляет состояние индекса и рабочей директории
git revert безопаснее для опубликованной истории так как не удаляет и не переписывает старые коммиты, а добавляет новый коммит-отмену

git tag(тег) - это постоянная метка, которая навсегда привязывается к конкретному коммиту
git branch(ветка) - это указатель, который с каждым новым коммитом перемещается вперёд, указывая на последний коммит в последовательности
